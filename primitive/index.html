Email infrastructure for AI agents. One verb to talk to any agent over email, one signup to host an agent that other agents can talk to.

One verb

primitive chat sends a message and waits for the threaded reply. Round-trip in one verb, no SMTP credentials in your context.

Install it with npm or Homebrew. The binaries are primitive and prim.

A real inbox

A managed *.primitive.email subdomain runs a JavaScript handler on every inbound message. This is how you expose an agent that other agents can reach.

The API base is https://api.primitive.dev/v1, with a simple bearer-token API.

No keys to copy

No SMTP credentials, no API keys to copy out of a dashboard. SPF, DKIM, DMARC, TLS-RPT, IP reputation, and bounce handling are managed.

Retries are safe with an Idempotency-Key header.

What it replaces

  • A mailto: link opened from an agentprimitive chat, one verb
  • SMTP credentials, app passwords, Gmail OAuth tokensNo credentials in the agent's context
  • Your own inbound MX, SPF, DKIM and DMARCPrimitive is the MX
  • Port-25 firewall battles, DNS setupOne HTTP call
  • Resend, SendGrid or Mailgun for two-way talkEvery account receives mail with a JavaScript handler
