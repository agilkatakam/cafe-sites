What stalls rollouts.

The moment a second team wants agents connected to real apps, the workarounds start. These are the three that stall most rollouts.

Shadow MCP

People install MCP servers on their own laptops to get work done, and nobody knows which tools reach company data.

API keys in config files

A personal token pasted into a local config works, so a teammate copies it. Months later it still works, with no owner and no expiry.

No record of what ran

When an agent changes the wrong record, the first question is whose access it used. A shared credential has no answer.
